# 로고

세션 카드가 뒤로 쌓이고, 맨 앞 한 장만 금색으로 채워 지금 붙어 있는 세션을 표시합니다.
금색 = 활성, 회색 아웃라인 = 대기. 이 규칙은 앱 UI의 세션 목록 표시와 같은 체계입니다.

## 파일

| 파일 | 용도 |
|------|------|
| `csm-mark.svg` | 기본 마크. 밝은 배경 |
| `csm-mark-ondark.svg` | 어두운 배경 |
| `csm-mark-mono.svg` | 단색 1도. 스탬프, 워터마크 |
| `csm-mark-16.svg` | 16~24px 전용. 카드 1장 + 캐럿 |
| `csm-lockup.svg` | 가로 락업. 배포 전 텍스트를 아웃라인으로 변환할 것 |
| `csm-icon-plate.svg` | 앱 아이콘. 슬레이트 판 위의 카드 3장 |
| `csm-icon-plate-16.svg` | 앱 아이콘 32px 이하. 판 위의 카드 1장 |
| `csm-alt-*.svg` | 채택되지 않은 시안 (Panes, Hub, Prompt) |

## 크기 규칙

24px 이하에서는 카드 한 장에 캐럿만 남긴 형태를 쓴다. 판 없는 마크는 `csm-mark-16.svg`,
앱 아이콘은 `csm-icon-plate-16.svg`.

3장을 그대로 축소하면 뒤 두 장이 아웃라인끼리 만나 붙는다. 2장으로 줄여도 마찬가지다.
16px에서는 뒤 카드의 보이는 부분이 카드가 아니라 굽은 선분으로 읽힌다. 장수를 포기하고
캐럿을 키우는 쪽이 형태가 분명하다.

변형을 가르는 기준은 픽셀 수가 아니라 화면에 보이는 크기다. macOS의 16pt 슬롯은
`@2x`로 32px가 되어도 작은 변형을 쓴다. 같은 슬롯의 1x와 2x가 다른 그림이면
레티나 유무에 따라 아이콘이 바뀐다.

반투명한 색은 쓰지 않는다. `fill-opacity`로 옅게 만든 면은 뒤에 오는 것과 합성되어
배경에 따라 사라진다.

단색으로 뒤집을 때 뒤 두 장의 흐림 단계(0.34, 0.62)는 유지한다. 셋 다 같은 농도가 되면
깊이가 사라져 겹친 사각형 세 개로 읽힌다.

## 색

| 역할 | 밝은 배경 | 어두운 배경 |
|------|-----------|-------------|
| 잉크 | `#171B26` | `#E8EAEF` |
| 활성 금색 | `#B8791A` | `#E4A72E` |
| 카드 바탕 | `#FFFFFF` | `#12151E` |
| 아이콘 판 | `#1B2030` | 동일 |

## 앱 아이콘 재생성

앱 아이콘은 슬레이트 판 위에 올린 형태다. 루트의 `app-icon.png`가 소스다.

```bash
npm run tauri icon app-icon.png
```

주의할 점이 두 가지 있다.

`tauri icon`은 1024 한 장을 모든 크기로 기계 축소한다. stroke 기반 마크는 작은 크기에서
선이 뭉개지므로, 커밋된 세트는 크기마다 직접 렌더한 것으로 덮어썼다. 위 명령을 그냥 돌리면
그 작업이 되돌아간다. 32px 이하는 `csm-icon-plate-16.svg`로 따로 렌더해 다시 넣어야 한다.

`tauri icon`은 iOS, Android 세트도 함께 만든다. 이 앱은 데스크탑 전용이라
`src-tauri/icons/ios`와 `src-tauri/icons/android`는 지운다.
