# 로고

세션 카드가 뒤로 쌓이고, 맨 앞 한 장만 금색으로 채워 지금 붙어 있는 세션을 표시합니다.
금색 = 활성, 회색 아웃라인 = 대기. 이 규칙은 앱 UI의 세션 목록 표시와 같은 체계입니다.

## 파일

| 파일 | 용도 |
|------|------|
| `csm-mark.svg` | 기본 마크. 밝은 배경 |
| `csm-mark-ondark.svg` | 어두운 배경 |
| `csm-mark-mono.svg` | 단색 1도. 스탬프, 워터마크 |
| `csm-mark-16.svg` | 16~24px 전용. 카드 1장 + 캐럿 |
| `csm-lockup.svg` | 가로 락업. 배포 전 텍스트를 아웃라인으로 변환할 것 |
| `csm-icon-plate.svg` | 슬레이트 판 위에 올린 앱 아이콘 변형 |
| `csm-alt-*.svg` | 채택되지 않은 시안 (Panes, Hub, Prompt) |

## 크기 규칙

24px 이하에서는 `csm-mark-16.svg`를 쓴다. 카드 한 장에 캐럿만 남긴 형태다.

3장을 그대로 축소하면 뒤 두 장이 아웃라인끼리 만나 붙는다. 2장으로 줄여도 마찬가지다.
16px에서는 뒤 카드의 보이는 부분이 카드가 아니라 굽은 선분으로 읽힌다. 장수를 포기하고
캐럿을 키우는 쪽이 형태가 분명하다.

아이콘은 투명 배경으로 나가므로 반투명한 색을 쓰지 않는다. `fill-opacity`로 옅게 만든
면은 뒤에 오는 것과 합성되어 어두운 독에서 사라진다.

단색으로 뒤집을 때 뒤 두 장의 흐림 단계(0.34, 0.62)는 유지한다. 셋 다 같은 농도가 되면
깊이가 사라져 겹친 사각형 세 개로 읽힌다.

## 색

| 역할 | 밝은 배경 | 어두운 배경 |
|------|-----------|-------------|
| 잉크 | `#171B26` | `#E8EAEF` |
| 활성 금색 | `#B8791A` | `#E4A72E` |
| 카드 바탕 | `#FFFFFF` | `#12151E` |
| 아이콘 판 | `#1B2030` | 동일 |

## 앱 아이콘 재생성

`src-tauri/icons/`의 전체 세트는 루트의 `app-icon.png`(1024px, 투명 배경)에서 나온다.

```bash
npm run tauri icon app-icon.png
```

독 아이콘을 투명 마크 대신 판 위에 올린 형태로 바꾸려면 소스를 갈아끼운다.

```bash
cp assets/logo/csm-icon-plate-1024.png app-icon.png
npm run tauri icon app-icon.png
```

`tauri icon`은 iOS, Android 세트도 함께 만든다. 이 앱은 데스크탑 전용이라
`src-tauri/icons/ios`와 `src-tauri/icons/android`는 지운다.
